# 学習した知識に基づくレビュー

ユーザが過去に指摘したことを、同じユーザに二度言わせないためのレビューである。
一般的な良し悪しではなく、**蓄積された知識に照らして** 対象を見る。

知識は、このスキルのディレクトリにある `knowledge/` に置かれている。

- `INDEX.md` — 知識の一覧。1 行が 1 つの知識で、「どんな対象のときに当てはまるか」と詳細ファイルへのリンクを持つ。
- それ以外の `.md` — 知識の詳細。1 ファイルが 1 つの知識。

## 1. レビュー対象を決める

ユーザが対象を指定していれば、それを対象にする。
指定が無ければ、まだコミットされていない変更を対象にする。それも無ければ、何をレビューするかをユーザに尋ねる。

対象は、変更された箇所だけでなく、その意味が分かるだけの周囲も読む。

## 2. 当てはまる知識を選ぶ

`INDEX.md` を最後まで読む。対象に当てはまり得る行について、詳細ファイルを開いて読む。
当てはまるか迷う行は、開く。索引の 1 行だけでは、当てはまらない場合の条件までは分からないため。

## 3. 照らし合わせる

開いた知識の 1 つずつについて、対象がそれに反していないかを確かめる。
詳細に「当てはまらない場合」が書かれていれば、それに該当しないことも確かめる。

知識に無い観点での指摘は、このレビューの指摘に混ぜない。
混ぜると、ユーザはどれが自分の過去の指摘に由来するのかを見分けられなくなる。
明らかな誤りに気づいたときは、指摘とは別に、最後に短く伝える。

## 4. 報告する

指摘ごとに以下を書く。

```
### <対象の場所> — <何が問題か>

**根拠の知識**: <詳細ファイルの名前>

**該当箇所**:
<対象の現物。該当する部分だけ>

**どう直すか**: <知識に沿った形>
```

指摘が 2 件以上あるときは、先頭に一覧を置く。

対象は直さない。直すかどうかは、報告を読んだユーザが決める。

指摘が無ければ、以下の一行だけを書く。照らした知識の一覧は書かない。

```
学習済みの知識に反する箇所はありません。
```

`INDEX.md` に知識が 1 つも無いときは、照らすものが無いことを伝えて終わる。
