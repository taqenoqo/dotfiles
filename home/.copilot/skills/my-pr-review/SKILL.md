# My PR Review

## 概要

この skill は、レビュー観点毎に専用の reviewer agent を起動する。
レビュー毎に subagent を起動することで、コンテキストに依存しない、客観的なレビューを得る。
そして、各 agent の出力をまとめたレポートを出力することで、ユーザーの PR レビューを助ける。

## 使うとき

- 大きな PR のレビューをするとき

## レビューエージェント起動手順

1. **git の SHA を取得:**

    ``` sh
    BASE_SHA=$(git merge-base origin/main HEAD)
    HEAD_SHA=$(git rev-parse HEAD)
    ```

2. **カスタムエージェントの起動:**

    `my-pr-review/*-code-reviewer.md` というグロブのパスに、レビュー観点毎の subagent の挙動を定義したファイルがあります。
    レビュー観点毎に、subagent を起動して、レビューをさせてください。

    ただし、 `*-code-reviewer.md` にはいくつかのプレースホルダがあるので、それらを埋めたものを subagent に指示として渡してください。

    * **プレースホルダ:**

        + `{BASE_SHA}`: 比較のベースとなるコミット
        + `{HEAD_SHA}`: 比較の対象となるコミット

3. カスタムエージェントがユーザー宛に確認を求めてきた場合は、それをユーザーに中継してください。
