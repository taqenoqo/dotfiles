# My Repo Report

## 概要

リポジトリ全体を調査し、構造地図レポートを対象リポジトリの `.repo-report/gen.md` に生成する。

実作業はすべてマネージャエージェント (`manager.md`) に委譲する。
メイン会話の文脈をレポートに持ち込まず、また会話履歴を全往復に引きずるコストを避けるためなので、以下の手順以外の作業を自分で行わないこと。

## タスク

1. **前提確認:**

    ``` sh
    REPO_ROOT=$(git rev-parse --show-toplevel)
    HEAD_SHA=$(git rev-parse HEAD)
    ```

    git リポジトリでなければ中止してユーザーに報告してください。

2. **モデル解決:**

    `model-resolution` スキルで `low` と `medium` の 2 つのモデル名を解決してください。

3. **マネージャエージェントの起動:**

    `manager.md` テンプレートのプレースホルダを埋め、サブエージェントを 1 体起動し、完了を待ってください。
    マネージャ自身のモデルは指定しないでください (デフォルトのモデルを引き継ぐ)。

    * **プレースホルダ:**

        + `SKILL_DIR`: このスキルのディレクトリの絶対パス
        + `REPO_ROOT`: 手順 1 の REPO_ROOT
        + `HEAD_SHA`: 手順 1 の HEAD_SHA
        + `LOW_MODEL`: 手順 2 で解決した low のモデル名
        + `MEDIUM_MODEL`: 手順 2 で解決した medium のモデル名

4. **結果の提示:**

    マネージャの最終返答 (gen.md の diff 要約・「人間への質問」の件数・台帳のファイル数) をそのままユーザーに提示してください。
