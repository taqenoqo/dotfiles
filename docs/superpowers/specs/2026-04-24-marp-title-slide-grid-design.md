# Marp my-theme タイトルスライド Grid 再設計

## 背景

`home/.config/marp/themes/my-theme.css` のタイトルスライドは、`section:has(h1)` 配下で `h1`、`h2`、著者情報を `position: absolute` と `bottom` 指定で個別配置している。

この方式は、要素を追加したいときに「どこに置くか」を毎回座標で考える必要があり、タイトル・サブタイトル以外の情報を自然に並べにくい。今回の目的は、タイトルスライドだけを CSS Grid ベースの構造に置き換え、斜めアクセントを維持しながら配置ルールを単純化すること。

## 目標

- 通常スライドの見た目は変えない
- タイトルスライドだけを absolute 配置から Grid 配置へ置き換える
- `h1` と `h2` は上段にまとめる
- `h1` / `h2` 以外の要素は `header` / `footer` を除いて下段にまとめる
- 斜め境界の中央帯には要素を置かない
- 既存の斜めアクセントの印象は保つ

## 対象範囲

変更対象は `section:has(h1)` に関するタイトルスライド専用スタイルだけに限定する。

- 変更するもの
  - `section:has(h1)` のレイアウト
  - タイトルスライド上の `h1`
  - タイトルスライド上の `h2`
  - タイトルスライド上の `h1` / `h2` 以外の本文要素
- 変更しないもの
  - 通常スライドの `h2` バー
  - 共通フォント設定
  - 色変数
  - `header` / `footer` の通常スライド向けルール

## レイアウト設計

### 1. タイトルスライドを 3 段 Grid にする

タイトルスライド全体を、上段・中央の空白帯・下段の 3 段 Grid として扱う。

- 上段: タイトル群の配置エリア
- 中央帯: 非配置エリア
- 下段: タイトル以外の情報の配置エリア

中央帯は、斜め背景の上端 40% と下端 60% のあいだに対応する余白として確保する。この帯にはコンテンツを置かない。

### 2. 要素の割り当て

Marp が出力する既存要素をそのまま使い、CSS 側で Grid のどこに属するかだけを決める。

- `h1`: 上段
- `h2`: 上段
- `header` / `footer`: 既存ルールのまま独立
- `h1` / `h2` 以外の直下要素: 下段

これにより、タイトルスライドのルールは「上段は `h1` / `h2`、残りは下段」という形に単純化される。

### 3. 上段の並び方

上段では `h1` と `h2` を縦方向に積む。`h1` を主タイトル、`h2` を補足情報として扱い、どちらも通常フローで並べる。個別の `bottom` 調整は行わない。

### 4. 下段の並び方

下段には `h1` / `h2` 以外の要素をすべて集める。著者情報などの本文要素は、右下固定ではなく下段の中で自然に並ぶ構成とする。

下段は水色アクセントの上に乗る前提なので、文字色は白系を基準にする。

## 見た目の設計

### 斜めアクセント

タイトルスライドの `::before` 疑似要素による斜め背景は維持する。形状の基準も現行に近いままとし、テーマの印象は継続する。

### 非配置エリア

斜め境界に文字が重なることを防ぐため、中央帯は完全な空白帯として扱う。見た目としては、白地側のタイトル群と、水色側の補足情報群のあいだに余白が入る構成になる。

### タイポグラフィ

- `h1`: 現行と同程度の強さを維持する
- `h2`: `h1` より軽い補足として扱う
- 下段要素: 水色帯に乗るため白系の文字色にする

## 実装上の方針

- 新しい HTML ラッパー要素は追加しない
- Marp の既存出力を前提に、セレクタだけで配置を切り替える
- タイトルスライド専用セレクタの中に変更を閉じる
- absolute な座標合わせではなく、Grid の段割りで配置を制御する

## 確認観点

- `h1` と `h2` が常に上段に収まること
- `h1` / `h2` 以外の要素が下段に流れること
- 40%〜60% の中央帯に要素が入らないこと
- 斜めアクセントの見た目が崩れないこと
- 通常スライドの見た目が変わらないこと
