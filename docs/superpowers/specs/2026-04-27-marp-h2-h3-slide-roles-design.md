# Marp my-theme: h2 / h3 の役割整理

## 問題

`my-theme` では、通常スライドの見出しバーに `h2` を使っている一方、タイトルスライドでも `h1` の下のサブタイトルとして `h2` を使っている。

今回の目的は、この 2 つの役割を明確に分けること。

- 通常スライドでは、既存の上端バー見出しを `h3` で表現する
- タイトルスライドではない `h2` 単独スライドを、区切りページとして扱う
- タイトルスライド（`h1` と任意の `h2`）の見た目は維持する

## 目標

- 通常スライドの見出しバーのスタイルを `h2` から `h3` に移す
- `h2` 単独スライド向けの専用区切りページレイアウトを導入する
- タイトルスライドの現在の挙動を変えない
- Markdown 上でも、見出しレベルを見れば役割が分かる状態にする

## 非目標

- タイトルスライド自体の再設計
- 複数種類の `h2` 区切りページバリエーションの導入
- `h2` に本文が続くスライドを特別レイアウトにすること

## Markdown 上のルール

### タイトルスライド

`h1` を使い、必要ならその後ろに `h2` を置く。

- `h1`: メインタイトル
- `h2`: サブタイトル

### 通常スライド

既存のアクセント色の上端バーを出したいスライドでは、見出しに `h3` を使う。

### 区切りページ

スライドの見える内容として `h2` だけを置く。

想定する Markdown は次の形。

```md
## Section Title
```

同じスライド内に、この `h2` の後ろへ段落・箇条書き・その他の本文要素は置かない。

## 想定する挙動

### 1. 通常スライド

タイトルスライドではない通常スライドでは、現在 `h2` に付いている見出しバースタイルを `h3` へ移す。

維持したい見た目は次のとおり。

- 上端に張り付くアクセント色のバー
- 現在と同じ負の margin と padding の構造
- 現在と同じ文字サイズと太さ

### 2. 区切りページ

タイトルスライドではなく、本文要素として `h2` だけを持つスライドは、専用の区切りページとして扱う。

見た目の方向性は次のとおり。

- 背景は全面アクセント色
- 内容は中央寄せ
- `h2` は大きめに見せる
- 文字色はアクセント色背景上で十分なコントラストを確保する
- 通常本文用のレイアウトは使わない

これはブレインストーミング時に選ばれた「全面アクセント色の強い区切りページ」案に対応する。

### 3. タイトルスライド

既存の `section:has(h1)` レイアウトはそのまま維持する。

維持対象は次のとおり。

- 斜め背景
- `h1` の配置
- `h2` のサブタイトル配置
- ページ番号位置

## selector 方針

### 通常スライドの見出しバー

既存の非タイトルスライド向け selector `section:not(:has(h1)) h2` はやめて、トップレベルの `h3` を対象にする selector へ変更する。

本文中のネストした見出しへ誤って適用しないよう、実装では直接子を対象にする書き方を優先する。

### 区切りページの判定

次の条件を満たす `section` を拾う selector を追加する。

- `h1` を含まない
- トップレベルの `h2` を含む
- その `h2` 以外のトップレベル本文要素を持たない

概念的には「`h2` だけを持つ非タイトルスライド」を拾う selector である。

これにより、区切りページの条件を明示しつつ、`h2` + 本文のスライドが誤って区切りページになるのを防ぐ。

## 想定する境界ケース

### 非タイトルスライドで `h2` の後ろに本文がある場合

このケースは区切りページとして扱わない。

専用の区切りページレイアウトを当てず、通常の文書フローへ落とす。

### `h2` も `h3` もないスライド

今回の変更では新しい挙動を追加しない。

### 本文中にネストした見出しがある場合

通常スライド用の見出しバーが、本文中のネストした見出しへ誤って適用されないようにする。

## 確認方針

少なくとも次のケースを確認する。

1. 通常スライドで `h3` が現在の見出しバーになること
2. `h2` 単独スライドが全面アクセント色の中央寄せ区切りページになること
3. `h1` と任意の `h2` を持つタイトルスライドが変わらないこと
4. 非タイトルスライドで `h2` の後ろに本文がある場合、区切りページにならないこと

## 実装メモ

- 変更は `home/.config/marp/themes/my-theme.css` に閉じる
- 新しい区切りページに必要な分を除き、既存のテーマ値は維持する
- 小手先の CSS トリックより、selector の分かりやすさを優先する
