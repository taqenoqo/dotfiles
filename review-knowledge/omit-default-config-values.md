# 設定ファイルに既定値と同じ値を書かない

## 指摘すること

設定ファイルに、ツールの既定値と同じ値や、既定値で足りる値が書かれていたら指摘する。既定値はツールの版で変わるので、使っている版の公式の情報で確かめてから指摘する。

## 理由

既定値で済むものは書かない、というのがユーザの方針。書いてあると、読み手は何のために既定値から変えているのかを探すことになる。

## 例

反している例: TypeScript 6 以降で、既定で有効な `"strict": true` を tsconfig に書く。

沿っている例: 既定値で足りないものだけを書く (Node の ES Modules として動かすための `"module": "nodenext"` など)。

## 出所

2026-11-15、TypeScript のプロジェクトの tsconfig を解説した際、既定値とほぼ同じ設定や、構成の変更で不要になった設定を「消せるものは消して」と指示された。
