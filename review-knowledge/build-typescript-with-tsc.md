# TypeScript は tsc でビルドする

## 指摘すること

TypeScript のプロジェクトが、tsc でビルドせず、型を取り除くだけで直接実行する構成 (Node の type stripping など) になっていたら指摘し、tsc でビルドして出力した JS を実行する構成を勧める。`erasableSyntaxOnly` のように、直接実行のために使える構文を制限する設定も、その印になる。

## 理由

ユーザが、どのプロジェクトにも当てはまる好みとして示した。きっかけは、型を取り除くだけの直接実行では parameter property などの構文が使えず、一般的なスタイルガイドに沿った書き方ができなかったこと。

## 例

反している例: `node src/main.ts` で実行し、tsconfig は `noEmit` と `erasableSyntaxOnly` で型チェック専用になっている。

沿っている例: ビルド用の tsconfig で `src/` を `dist/` に出力し、`node dist/main.js` で実行する。

## 当てはまらない場合

未確認。

## 出所

2026-11-15、TypeScript の CLI ツールを型の除去だけで直接実行する構成にしていたところ、ビルドしていないことにユーザが驚き、「tsc でビルドするようにしろ」と指示された。のちに、どのプロジェクトにも当てはまる好みだと確認した。
