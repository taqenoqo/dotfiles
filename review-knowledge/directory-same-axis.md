# 同じ階層のディレクトリは分類軸を揃える

## 指摘すること

同じ階層に並ぶディレクトリの名前が、違う分類軸 (層の名前と、扱う対象の名前など) で混ざっていたら指摘する。軸ごとに階層を分け、たとえば 1 階層目を層、2 階層目を対象にするよう求める。

## 理由

軸が混ざると、どれが層でどれが対象なのかが読み取れず、構成の意図が分からなくなる。モノを並べるときは同じ抽象度で揃える、というユーザの一般方針をディレクトリに当てはめたもの。

## 例

反している例:

```
src/
  domain/
  usecases/
  payment/      ← 層ではなく対象の名前
```

沿っている例:

```
src/
  domain/
  usecases/
  adapters/
    payment/
```

## 当てはまらない場合

未確認。

## 出所

2026-11-15、CLI ツールのディレクトリ構成の提案で、層の名前と対象の名前を同じ階層に並べた案に対し、「層がどうなってるかわからない」「同列のもので並べろ」と指摘された。
